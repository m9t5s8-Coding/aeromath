# AeroMath 🚀

A simple and lightweight C++ mathematics library for vector and matrix operations.

## Features

### Vectors

- `Vec2` — 2D vector
- `Vec3` — 3D vector
- `Vec4` — 4D vector

### Matrices

- `Mat2` — 2×2 matrix
- `Mat3` — 3×3 matrix
- `Mat4` — 4×4 matrix
